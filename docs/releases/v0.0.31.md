## Highlights ⭐️

* **Quotes escaped in tag and navigation HTML**: A `'` or `"` in a page title, tag name, permalink or file name could close an HTML attribute on tag pages and navigation menus and inject attributes such as event handlers. Both now use `metadata_gen::utils::escape_html`, and tag names, previously written raw, are escaped too.
* **Raw HTML changes for quoted titles**: Titles and tag names containing quotes now appear as `&quot;` and `&#x27;` in the HTML source. Browsers show the same text; tests or tools that compare raw HTML will see the difference.
* **Dependency refresh**: `comrak` moves to `0.59.0` and `uuid` to `1.29.0`, with updated Quality workflow action pins.
