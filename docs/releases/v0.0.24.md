## Highlights ⭐️

* **Engine and dependency consolidation**: Consolidated Markdown processing on `comrak` and XML generation on `quick-xml`, eliminating redundant `pulldown-cmark` and `xml-rs` crates.
* **In-memory HTML minification**: Switched HTML file writes to direct in-memory minification before disk output via `minify_html_string`, avoiding redundant post-write read-write filesystem roundtrips.
* **Supply chain footprint reduction**: Pruned unused exemptions for removed dependencies (`pulldown-cmark`, `pulldown-cmark-escape`, `unicase`) in `supply-chain/config.toml`.
