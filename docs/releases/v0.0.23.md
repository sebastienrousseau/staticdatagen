## Highlights ⭐️

* **Body content language wrapper fixed**: The Markdown body renderer now uses `html-generator`'s default language rather than hard-coding `"en"`, eliminating the unintended `<div lang="en">` wrapper around page fragments. Non-English pages retain their correct `<html lang>` attribute for screen readers, meeting WCAG 3.1.1, and CSS selectors targeting adjacent prose elements (`.prose > * + *`) work as intended (fixes #139).
* **Lax undefined mode in template engine**: Layout rendering now configures `staticweaver` with `with_lax_undefined(true)`, emitting empty strings for missing front-matter variables instead of failing with unresolved tag errors. Downstream generators no longer need to shim empty defaults into source files (closes #99).
* **Pipeline architecture visualization**: Added a Mermaid architecture flowchart to `docs/ARCHITECTURE.md` documenting the compilation data flow from directory walk through parsing, rendering, aggregation, and sanitized file output (closes #93).
* **Engine and dependency consolidation**: Consolidated Markdown processing on `comrak` and XML generation on `quick-xml`, eliminating redundant `pulldown-cmark` and `xml-rs` crates. Replaced post-write file minification with direct in-memory HTML minification before disk writes.
