## Highlights ⭐️

* **Hostile YAML front matter is refused**: `html-generator` 0.0.12 and `metadata-gen` 0.0.8 move `noyalib` to 0.0.56 for RUSTSEC-2026-0333, so a few hundred bytes of front matter built from nested aliases can no longer expand into megabytes.
* **Meta tags follow the specs**: Open Graph tags render with `property=` instead of `name=`, and meta tag values escape `&`, `<` and `>`. Both change the HTML a page carries, so check any layout or test that matches on the old tags.
* **Front matter stays out of the page**: TOML, JSON and BOM-prefixed pages used to show their own front matter as body text, or stop the build; they now render only their body.
