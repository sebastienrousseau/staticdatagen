## Highlights ⭐️

* **News sitemap XML declaration**: `news-sitemap.xml` starts with `<?xml version="1.0" encoding="UTF-8"?>` again, as it did before the move to `quick-xml` in 0.0.24.
* **ammonia 4.1.8 (RUSTSEC-2026-0373)**: CSS `url()` is matched case-insensitively, so `Url(...)` no longer slips past URL filtering in sanitised HTML.
* **comrak 0.56**: several denial-of-service fixes in the Markdown parser, with a new test that renders `<`, `>`, `&` and `"` at every offset up to 160 bytes to show the new SIMD-based escaper misses none.
* **Every dependency vetted**: the 21 crate versions the updates bring in are audited or covered by a trusted publisher, and nine stale exemptions are pruned.
