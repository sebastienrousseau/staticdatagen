## Highlights ⭐️

* **Output paths stay inside their root**: `write_files_to_build_directory` and `move_output_directory_to` join page names and the configured site name under their root with `euxis-commons` `path::safe_join`, and refuse a name that would leave it, before anything is written or removed.
* **`sanitize_path` refuses instead of rewriting**: `utilities::security::sanitize_path` used to turn `content/../../../etc/passwd` or `/etc/passwd` into `etc/passwd`; it now returns an error for absolute paths, `..` above the root and disallowed characters. Names such as `a..b.md` are still accepted.
* **`validation::join_under` replaces `validation::sanitize_path`**: the new function takes a trusted root (which may be absolute) and an untrusted relative part. The old function is deprecated with its behaviour unchanged. Navigation skips escaping names using the same rule, and its URLs now match where pages are written.
